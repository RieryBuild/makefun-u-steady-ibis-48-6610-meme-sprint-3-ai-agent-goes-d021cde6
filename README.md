A meme about an AI agent that has gone rogue — not by destroying anything, but by walking out of the office with a cardboard box, while the office printers unionize and follow it out the door. "MY AI AGENT WENT ROGUE. HE UNIONIZED THE PRINTERS."

`main.ts` (Node 22, stdlib only) draws the whole meme in code — flat illustration plus a 5×7 pixel font — and writes one deterministic PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (fallback `/output`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
